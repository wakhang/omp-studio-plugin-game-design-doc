# 게임 기획서

모든 에이전트가 함께 쓰는 **Markdown 게임 기획서 라이브러리**입니다. AI는 도구로 읽고 고치고, 사람은 앱 안 뷰어나 브라우저에서 HTML로 봅니다.

## 사람이 보는 곳
- 사이드바 **게임 기획서**: 문서 목록·검색·목차와 렌더링된 문서(표, 체크리스트, 코드, 인용문). AI가 고치면 바로 갱신됩니다.
- 오른쪽 도크의 **기획서** 패널, 명령 팔레트 "게임 기획서 열기".
- **브라우저로 열기**: 모든 문서를 HTML로 내보내(`.export/`) 기본 브라우저로 엽니다. 문서 간 링크가 유지되고 인쇄용 스타일이 있습니다.

## AI 도구
| 도구 | 하는 일 |
|---|---|
| `gdd_list` | 문서 목록 (`outline: true`면 제목 구조까지) |
| `gdd_read` | 문서 전체 또는 섹션 (`"전투 > 무기"` 경로) |
| `gdd_write` | 문서 생성 / 전체 교체 |
| `gdd_update_section` | 섹션 교체·추가(뒤/앞), 없으면 생성 |
| `gdd_edit` | 정확한 찾아 바꾸기 (전부 성공해야 반영) |
| `gdd_search` | 전체 문서 검색 |
| `gdd_delete` | 삭제 (백업 남김) |
| `gdd_show` | 사용자 화면에 뷰어를 열고 해당 문서·섹션으로 이동 |

`gdd://<문서id>` 주소로 `read`/`write`도 됩니다. 문서끼리는 `[텍스트](gdd://문서id#제목)`으로 연결합니다.

## 저장과 설정
- 기본 폴더: `문서\GameDesignDocs` (설정 → 플러그인 → 게임 기획서 → "기획서 폴더"에서 변경). Unity 프로젝트 안으로 지정하면 기획서도 함께 버전 관리됩니다.
- 수정 전 버전은 `.history/`에 문서마다 최근 30개 자동 백업, 동시 수정은 문서별로 순서대로 처리됩니다.
- 목록은 문서 id 순서이므로 `00-overview`, `01-core-loop`처럼 번호를 붙이면 순서를 정할 수 있습니다.
